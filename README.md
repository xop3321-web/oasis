# 오아시스 근무표

요양보호팀 근무표 웹앱의 첫 구현입니다. 어두운 배경, 라임 포인트, 카드형 대시보드와 PC·모바일 화면을 제공합니다. 현재 GitHub 업로드, Vercel 배포, 실제 계정 연동은 완료되지 않았습니다.

## 실행과 검증

Node.js 22 이상에서:

```sh
npm ci
npm test
npm run dev
npm run build
```

로컬 Vite에서는 가상 직원 데모로 실행됩니다. 데모 자료는 현재 브라우저에만 보관되며 다른 기기와 공유되지 않습니다. Vercel 서버 API가 설정된 경우에만 실제 계정과 공용 저장소를 사용합니다. 데모에 실제 개인정보를 입력하지 마세요.

## 구현 범위

- 4개 층 근무표, 퐁당당 순환 및 다음 달 연결, 주간 지원 자동 배정
- 목욕 요일·날짜 예외, 월 기준시간 직접 입력, 필수 공백 및 관계 경고
- 직원 추가, 재직 기간, 소속 이동일, 가능 근무유형, 담당층
- 연차 신청·검토·승인·취소, 엑셀 입력, 사진 문자 인식 후 확인
- 수동 휴일 시간 적립·사용 장부, 잔액 초과 방지
- 직원 협의 요청·승인, 초안과 공개본 분리, 공개 이력
- 직원 전체층 조회, 팀장 의견 제출, 관리자 편집 권한
- 실제 근무 정정 기록·확인, 변경 감사기록
- 엑셀 내보내기, 인쇄, 규칙 기반 참고 사례의 활성·비활성
- 카카오 OAuth 서버 구현, 서명 세션, CSRF, 서버 권한 확인
- Apps Script 공유 저장소, 동시 수정 시 버전 충돌 차단

## GitHub 및 Vercel

비공개 빈 GitHub 저장소 `oasis-roster`에 이 폴더의 파일을 업로드하세요. node_modules와 .env는 제외합니다. Vercel에서 저장소를 Import하고 Framework는 Vite, Build Command는 `npm run build`, Output Directory는 `dist`로 설정합니다. 설정은 vercel.json에도 포함되어 있습니다. Node.js 22를 사용하세요.

설정 없이 배포하면 명시적으로 표시된 데모가 열립니다. 실사용으로 전환하려면 아래 설정 후 재배포해야 합니다.

## 구글 스프레드시트 연결

1. 관리자 소유의 비공개 스프레드시트를 만듭니다.
2. 확장 프로그램 → Apps Script에 `integrations/google-apps-script.gs`를 넣습니다.
3. 스크립트 속성에 `SPREADSHEET_ID`와 임의의 긴 비밀값 `OASIS_SECRET`을 넣습니다.
4. 웹 앱으로 배포: 본인으로 실행, 모든 사용자 접근. 요청마다 비밀값을 서버에서 검증합니다. 직원에게 시트와 스크립트 편집권한을 주지 않습니다.
5. 배포 URL을 Vercel의 `APPS_SCRIPT_URL`, 같은 비밀값을 `APPS_SCRIPT_SECRET`에 넣습니다.

시트는 구조화된 앱 상태를 분할·인코딩하여 저장합니다. 직접 셀을 수정하는 근무표가 아닙니다. Apps Script 저장 용량·실행 할당량, 장기 감사기록 보관과 정기 백업은 운영 시작 전 확인해야 합니다.

## 카카오 로그인과 최초 관리자

카카오 개발자 앱에서 로그인과 웹 플랫폼을 활성화하고 서비스 도메인과 리다이렉트 URI `https://실제도메인/api/auth?op=callback`을 등록합니다. 다음 Vercel 환경변수를 설정합니다. 비밀값을 소스나 채팅에 붙여넣지 마세요.

| 변수 | 내용 |
|---|---|
| APP_URL | 실제 HTTPS 앱 주소, 마지막 / 제외 |
| KAKAO_CLIENT_ID | 카카오 REST API 키 |
| KAKAO_CLIENT_SECRET | 카카오 Client Secret, 활성화한 경우 |
| SESSION_SECRET | 32자 이상 임의의 비밀값 |
| INITIAL_ADMIN_KAKAO_ID | 최초 사무국장의 카카오 앱 사용자 ID |
| APPS_SCRIPT_URL | 배포한 Apps Script 웹 앱 URL |
| APPS_SCRIPT_SECRET | 스크립트의 OASIS_SECRET과 같은 값 |

처음 로그인한 직원은 승인 대기 상태입니다. 최초 사무국장은 환경변수의 앱 사용자 ID로 연결하고, 이후 직원 정보와 계정을 연결합니다. 최초 관리자 ID를 모르면 로그인 후 표시되는 자신의 앱 사용자 ID를 관리자 설정에 사용합니다. 카카오 개발자 설정과 실제 기기 로그인은 아직 검증하지 않았습니다.

## 현재 한계와 운영 전 확인

- 자동편성은 설명 가능한 휴리스틱 초안입니다. 전역 최적해나 모든 결원의 자동 해결을 보장하지 않습니다. 금지 관계가 있으면 경고하고 공개를 차단하며, 자동으로 조를 재구성하지는 않습니다.
- 관리자 참고 사례는 요일·직원·층 선호를 재적용하는 규칙입니다. 머신러닝 모델이 아닙니다. 관계 2단계는 분리 검토 경고입니다.
- 팀장 퐁 대체·다른 조 추가근무는 협의 후 수동 확정합니다. 야간·새벽 대체 편성은 없습니다.
- 실제 근무는 수정 이력으로 보관합니다. 대시보드 월 시간은 계획 기준이며 실제 정정으로 연차·시간 장부를 자동 변경하지 않습니다.
- 연차는 수동 기초 잔액과 승인 차감으로 관리합니다. 입사일 기반 법정 자동 발생, 케어포 직접 연동은 구현되지 않았습니다.
- 공휴일 적립은 수동이며, 공단 인정시간이나 법률 적합성을 자동 판정하지 않습니다. 사용자가 확인한 월 기준시간을 입력합니다.
- 사진 OCR 결과는 반드시 확인해야 합니다. 원본 증빙 영구 저장은 포함하지 않습니다.
- 자동편성 재실행은 수동 초안을 다시 만듭니다. 승인된 협의 요청은 유지되지만 개별 직접 수정은 재검토해야 합니다.
- 운영 시작 전 실제 근무표 대조, 동시 관리자 수정, 카카오 로그인·퇴사 계정 차단, 모바일 기기, 복구·백업, Google 할당량을 검증해야 합니다.
